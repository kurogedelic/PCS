Keyboard: A W S E D F T G Y H U J K. EG 1 → VCA, EG 2 → WARP/DCW modulation. OUT A/B are proposed hardware outputs; the browser preview is mono. AR(D) LOOP uses attack → hold → release cycling while gate is held. REZ implements the phase-multiplied sine and SAW/TRI/TRAP/PULSE/DOUBLE SAW windows from CrispyZebra. WARP controls DCW; WIDTH controls the window span (default .5 is the reference shape). WAVE uses phase distortion. No dry/resonance mix or VCF; the separate Q control is deferred. The 40HP layout is conceptual, not a mechanical clearance drawing.
